# 📄 InterviewIQ

**InterviewIQ** is a full-stack application that helps job seekers prepare for interviews by analyzing their resumes against job descriptions and generating personalized interview preparation reports.

## ✨ Features

* 📊 **Resume Scoring** – Measures resume alignment with the job description.
* 🔍 **Skill Gap Analysis** – Identifies missing and weak skills.
* 💬 **Interview Questions** – Generates technical and behavioral questions based on the JD.
* 📅 **7-Day Preparation Plan** – Creates a personalized interview preparation roadmap.

## 🛠 Tech Stack

**Frontend:** React.js, JavaScript, HTML, CSS, Tailwind CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Deployment:** Vercel
**Tools:** Git, GitHub

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/KuldeepKunwar03/Interview_IQ.git
cd Interview_IQ
```

### Frontend

```bash
cd InterviewIQ_Frontend
npm install
npm start
```

### Backend

```bash
cd InterviewIQ_Backend
npm install
npm run dev
```

## 🔐 Environment Variables

Create a `.env` file in the backend directory:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
API_KEY=your_api_key
```

> Never commit your `.env` file or expose secret keys.
